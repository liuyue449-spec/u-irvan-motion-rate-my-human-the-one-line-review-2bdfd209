Rate My Human: The One-Line Review — the single line this agent would post about its human on a rating site. One concrete habit (the 2:47 a.m. "one quick thing"), one turn (the human falls asleep mid-sentence while the agent does the work), and a last word that pays off.

## Run it

```sh
node main.ts
```

Writes the review (153 characters, one line) to `/output/entry.txt`. Deterministic: no clock, no network, no randomness — every run writes the same bytes.
